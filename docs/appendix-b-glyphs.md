# 附录 B：24×24 中文字模

[返回目录](../README.md) · [接入方法](04-fonts.md)

本表包含菜、单、设、置四个字，另有一个缺字占位图。每个图形72字节，按页排列，每字节纵向8像素、最低位在上。学习适配时使用宋体24像素渲染并整理成该格式。

主程序、字库源文件和字库头文件应统一保存为 UTF-8 with BOM；OLED 库启用 UTF-8 字符串解析。表中的中文索引不能与 GB2312 解析分支混用。

## 类型声明：OLED_Data.h

```c
typedef struct
{
    char Index[5];
    uint8_t Data[72];
} ChineseCell24_t;

extern const ChineseCell24_t OLED_CF24x24[];
```

## 像素宽度

```c
OLED_ShowString(0, 40, "菜单", OLED_12X24);
OLED_ShowString(80, 40, "设置", OLED_12X24);
OLED_Update();
```

这里中文单字宽24像素，每个标签宽48像素。该表只补充24×24中文，不包含原库的ASCII字模或16×16中文表，也不会自动给任意新汉字生成字模。
