# 整个工程的模块化实作教程

[返回仓库首页](../../README.md)

本教程以2026-11-07本地 `Core + Drivers + bsp + MDK-ARM` 工程为基准，目标是让你能解释每个变量、画出逻辑、按顺序手写功能，再与现有实现核对。学习顺序按依赖排列，不按文件名字母排序。

## 两条路线分别学

**移植路线**：取得已有库或素材 → 确认来源与接口 → 接入本工程 → 修改硬件相关部分 → 单独验证。OLED图形算法、原有字库、图标、动画素材属于这一部分；HAL、CMSIS、启动文件由工具链和CubeMX提供。

**自己编码路线**：定义需求 → 确定输入输出 → 设计变量 → 写出状态变化 → 先实现最小功能 → 增加完整交互 → 验收。应用调度、各页面、硬件适配、事件消费与游戏规则按此路线讲解。页面组织和交互参考原课程；“自己编码”表示学习时手工实现这些逻辑，不把参考代码或素材改称原创。

每章固定顺序：设计思想、变量与逻辑、A移植、B自己编码、验收与边界。可以先连续完成A路线，再逐章完成B路线；也可以每章先A后B。不要同时复制整页成品和再粘贴同名手写函数。

## 源码怎么配合阅读

[reference目录](reference/README.md)保存了当前工程31份小型源文件/头文件的逐字节快照，供每一步完成后对照。它们不是另一套固件，也不是可直接编译的完整工程。完整OLED库、字库/压缩数据、HAL/CMSIS和Keil工程已包含在仓库的 [firmware目录](../../firmware/README.md)，构建和测试均在该目录进行。

各章的“当前实现”讲现有行为；“后续改进练习”明确指出尚未写入当前固件的内容。源码与教程一起发布，文档列出的后续改进不会因打包上传而自动实现。

## 当前实现范围

| 能力 | 源码现状 |
|---|---|
| 首页时间 | 每轮尝试RTC读取，成功后刷新RAM缓存 |
| 设置 | 六字段可编辑，未做完整范围/合法日期校验，未写回RTC |
| RTC启动 | 每次初始化仍设置默认日期时间；无备份标记保护 |
| 菜单 | 0返回、1秒表、2PB15、3占位、4游戏、5KUN、6时钟测试 |
| 秒表 | 秒级计时；静态状态跨页面保留，离开期间不累计 |
| 游戏 | 跳跃、暂停、逐像素碰撞、计分；最高分仅RAM保存 |
| 动画 | 当前入口为45帧KUN，早期六帧表情是历史版本 |
| 预留宏 | `hi2c2`、`hadc1`、电池、关机等宏不代表功能已实现 |

原始设计与课程见[BQT0411/STM32-WATCH](https://github.com/BQT0411/STM32-WATCH)。OLED库沿用江协科技原署名；动画来源见[素材记录](../kun-dance.md)。
