## 历史教程与来源

这是一份配合 STM32F103C8T6 手表复刻工程使用的学习教程。按照“一次实现一个功能”的方式，从底层 GPIO、OLED、按键开始，逐步完成页面选择、设置页、日期时间字段选择和年份编辑。

参考设计来自 [BQT0411/STM32-WATCH](https://github.com/BQT0411/STM32-WATCH)。原工程使用标准库，本教程用 **STM32CubeMX + HAL + Keil** 实现相同的页面组织和按键交互，并说明在 VS Code 中编辑时的配置方法。

## 阅读和使用方式

1. 从原作者仓库获取配套源码，保留 OLED 库及其原有署名。
2. 建立自己的 CubeMX HAL 工程，按第 02 章配置外设。
3. 按章节手工添加代码。出现“替换”时不要把同名函数再粘贴一遍。
4. CubeMX 生成区域继续交给生成器管理，自定义逻辑放在 `USER CODE BEGIN/END` 区域。
5. 使用附录 A 核对当前阶段的最终结构。

本仓库现在同时提供模块教程、历史代码片段和 [当前完整固件源码工程](firmware/README.md)。原01～12章继续保留早期练习内容；构建当前固件使用 `firmware/MDK-ARM/watch_1-2.uvprojx`，二进制由本机构建生成。
